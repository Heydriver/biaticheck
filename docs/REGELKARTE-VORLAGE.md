# Vorlage: Prüfprotokoll und Regelkarte

Für jede Musterprüfung ein Prüfprotokoll ausfüllen. Für jede neue Erkenntnis eine Regelkarte anlegen.

## A) Prüfprotokoll je Abrechnung

| Feld | Eintrag |
|---|---|
| Fall-Nr. | z. B. G-007 |
| Art | Mietwohnung / WEG / mit Gewerbe / mit Heizkostenabrechnung |
| Vorliegende Unterlagen | Abrechnung, Heizkostenabrechnung, Mietvertrag, Vorjahr, Belege |
| Gesamtdauer der Prüfung | Minuten |

Je Prüfschritt:

| Nr. | Was prüfe ich? | Welche Daten/Unterlagen? | Wie rechne/vergleiche/entscheide ich? | Ergebnis | Was erfährt/tut der Kunde? | Bestehende Regel-ID oder NEU |
|---|---|---|---|---|---|---|
| 1 | | | | ok / Abweichung / Auffälligkeit / nicht prüfbar | | |

**Gesamtergebnis des Experten:** Einsparpotenzial in €, wichtigste Punkte, Empfehlung.
→ Dieses Ergebnis wird als „erwartetes Ergebnis“ ins Golden Set übernommen.
