# BiatiCheck Erklärvideo (Remotion)

25-Sekunden-Video im Design von biati.de (Inter, #0E3B2E / #1FA37E / #2E7BB8, Glaskarten).

```bash
pnpm --filter @biaticheck/video studio            # Vorschau und Bearbeitung im Browser
pnpm --filter @biaticheck/video render            # 1920×1080 → out/biaticheck-erklaervideo.mp4
pnpm --filter @biaticheck/video render:hochkant   # 1080×1920 für Social Media
```

Schrift und Logo liegen lokal in `public/` – das Rendern braucht keinen externen Font-Server.

**Lizenz:** Remotion ist für Einzelpersonen und Unternehmen bis 3 Mitarbeitende kostenlos, darüber ist eine Firmenlizenz nötig (remotion.pro/license).
