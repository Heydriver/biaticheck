# BiatiCheck – Testseite (GitHub Pages)

Dieser Branch enthält nur die fertig gebaute Testseite (`index.html`) für GitHub Pages.
Er wird bei jedem Push auf `main` automatisch aus `apps/testseite` neu erzeugt. Bitte hier nichts von Hand ändern.

Hinweis: Außerhalb von claude.ai funktioniert nur „Beispiel ansehen“. Eigene Abrechnungen lassen sich nur über die Testseite bei Claude auslesen.
